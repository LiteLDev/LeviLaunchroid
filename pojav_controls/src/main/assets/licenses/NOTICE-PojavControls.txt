Pojav Controls compatibility library

This library is a modified Android/Bedrock port of the PojavLauncher custom-controls system and control-profile format from the supplied PojavLauncher-3_openjdk source distribution.

Upstream project: https://github.com/PojavLauncherTeam/PojavLauncher

The host communicates with this library through PojavControlsHost and may be rebuilt or relinked with a modified version of this library from the complete source tree.
